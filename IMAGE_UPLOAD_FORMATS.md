# Image upload formats

The Kairos Addis image uploader now accepts JPG/JPEG and PNG images for all image-library upload targets.

- Extensions: `.jpg`, `.jpeg`, `.png`
- MIME types: `image/jpeg`, `image/png`
- Maximum size: 10 MB
- Drag-and-drop and file-browser uploads use the same validation.
- Portal document upload continues to accept image files and PDF documents.
